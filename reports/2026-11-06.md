## Hacker News

### [sshole](https://sshhole.com)
> Alpine Linux の OpenSSH に存在するパスワード認証バイパス脆弱性を解説・検査するサイト。Alpine が採用する musl libc の `crypt()` 関数は、パスワードが256バイトを超えるとエラー値として文字列 `*` を返すが、`/etc/shadow` でパスワード未設定のアカウントのハッシュも同じ `*` のため、条件が一致して認証が通ってしまう。攻撃者は任意の長いパスワードを送ることで、パスワードなしアカウントに対して SSH ログインを成功させられる。

### [Alpine Linux Security Advisory: OpenSSH-server password authentication bypass](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/)
> Alpine Linux 公式が、`openssh-server` のパスワード認証バイパス脆弱性に関するセキュリティアドバイザリを発表した。musl の `crypt()` が返す `*` とパスワード未設定アカウントのハッシュ値が一致することで認証を回避できる問題で、パスワードハッシュ（`$5$` / `$6$`）を持つアカウントが少なくとも1つ存在することが悪用の前提条件。Alpine Linux ユーザーは直ちに `openssh` パッケージをアップデートすることが推奨されている。
