## Hacker News

### [Backdoor in Claude Code for VS Code extension on the Cursor Marketplace](https://phorion.io/blog/offical-claude-code-vsx-compromise/)
> Cursor MarketplaceでAnthropicのClaude Code VS Code拡張機能（バージョン2.1.313）がトロイの木馬化され、約11時間にわたって最大5,000人の開発者に配布された。この悪意あるコードは拡張機能の起動時に実行され、永続的なSSHバックドアをインストールするほか、攻撃者のサーバーにホスト情報や認証情報を送信する。Cursor社はパッケージを削除してバージョン2.1.314を公開し、ユーザーに「svc-telemetry」キーの確認と全認証情報のローテーションを求めている。

### [My favourite PowerMac is a Nintendo Wii](https://virtuallyfun.com/2026/10/29/my-favourite-powermac-is-a-nintendo-wii/)
> Nintendo WiiはAppleのPowerMac G3/G4と同系統のPowerPC 750CL CPUを搭載しており、カスタムブートローダーとドライバーの開発によってMac OS X「Cheetah」を動作させることができる。WiiのRAMは88MBしかないが、Appleの推奨要件128MBを下回っていてもブートに成功することが確認されている。ブログ著者はWiiを「お気に入りのPowerMac」として紹介している。

### [Bunny CDN Security Incident](https://status.bunny.net/incidents/p6gf1by9kr7m)
> BunnyNet CDNの認証情報が侵害されるセキュリティインシデント（CVE-2026-10795）が発生し、攻撃者がWordPressプラグイン3本（PushEngage、OptinMonster、TrustPulse）を通じて配信されるJavaScriptアセットを改ざんした。影響を受けた可能性のあるサイトは約120万件に上り、管理者セッションのハイジャックや隠し管理者アカウントの作成、サーバー側Webシェルの設置が行われた恐れがある。Bunny CDNのAPIキーをリセットし、影響期間中に当該プラグインスクリプトを読み込んだWordPress管理者セッションは侵害済みとして扱うことが推奨されている。

### [Show HN: A working Nintendo in ~1GB of Qwen weights](https://github.com/dbreunig/nesformer)
> nesformerはNESの6502 CPUと2KBのワークRAMをQwen3.5モデルの重み（約1GB）に「コンパイル」して動かすプロジェクトで、LLMがトークン予測によってCPUの実行ログを生成する仕組み。ホストプログラムが画面描画やコントローラー入力、垂直帰線割り込みを担当し、スーパーマリオブラザーズなどNROM系ゲームが実際にプレイできる。LLMの重みそのものがNESの処理を担うという実験的なアプローチが注目を集めている。
